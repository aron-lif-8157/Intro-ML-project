# Setup
1. To run this project create a environment
    python3 -m venv .venv
2. activate the environment
    source .venv/bin/activate
3. Install dependencies
    pip install numpy pandas scikit-learn matplotlib tqdm jupyterlab ipykernel

install extensions for your IDE
    VS-code : Pyhton (microsoft), Jupyter (microsoft)

# Requirement.txt
this file have the names of the installed dependensies for this project (we installed them in step 3)
